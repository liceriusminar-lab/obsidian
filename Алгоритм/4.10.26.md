Управление окнами и их интерфейсом в QT.
При создании пустого класса формы создаётся создаётся 3 файла:
	1. Файл с исходным кодом класса(для mainwindow:mainwindow.cpp)
	2. Заголовочный файл(mainwindow.h)
	3. Файл интерфейса(mainwindow.ui)
Имя каждого файла зависит от настоек проекта, по умолчанию используется имя класса без регистра.
Как в обычном языке C и  C++ основным комплериуемым файлом является main.cpp.
Чтобы создать окно необходимо в main.cpp подключить заголовочный файл окна и создать переменную с типом данных класса окна.
При создании класса формы создаётся новый указатель с именем ui который хранит информацию об элементах интефейса. 
При создании формы вызываетя метод setupUi(this) который запичывает инициализируют информацию об интерфейсе.
В диструктаре класса форма ~ИмяКлассаФормы в диструктаре указаль на ui удаляется.
У каждого элемента интерфейса есть свои собственные слоты(фукнции с типом данных void которые сигнализируют о каком-то событии(например если нажата кнопка или курсор находится в опр. облости и т.д.))
